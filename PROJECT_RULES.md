# Aetheris Project Rules

## Branch Rules
- Never push directly to main
- frontend branch → UI work
- dev branch → integration testing
- main branch → stable production-ready code

## Code Rules
- Keep components reusable
- Use clean folder structure
- Avoid hardcoded values
- Use consistent naming conventions

## UI Rules
- Premium light enterprise SaaS style
- Clean layouts with soft shadows
- Minimal but modern animations
- Professional analytics dashboard feel
- Avoid flashy AI/cyberpunk designs

## AI Rules
- AI must remain logistics-focused
- No generic chatbot features
- Recommendations should feel operational and intelligent

## Commit Rules
Use clean commit messages:
- Added dashboard layout
- Implemented shipment API
- Added AI recommendation logic

## Product Goal
Build an enterprise-grade AI operational intelligence platform for logistics networks.
